## 1. What is tracking stage doing
The tracking stage continuously tracks the code and carrier of the received GNSS signal to obtain precise synchronization parameters, which are used for Position, Velocity, and Time (PVT) estimation.
1. code wipe off -> fine frequency estimation -> $\hat{f}_{d,i}$
2. carrier wipe off -> fine delay estimation -> $\hat{\tau}_i$
## 2. Wipe off
For a good estimation of residual carrier frequency and code delay, wipe off code and residual modulation is important

## 3. Carrier Tracking
#### 3.1 Code Wipe-Off
$S[n] = C_b(nT_s-\hat{\tau})Y_{IF}(n)$
Right now
$S[n]=\sqrt{2P_R}a(nT_s)d_i(nT_s-\tau)cos(2\pi(f_{IF}+f_d)nT_s+\phi)$
where
$a(nT_s)$ is a residual modulation after code wipe-off, if don't remove it, it could lead a misalignment between incoming signal and local signal.
In Analog domain we can see the spike when there is a change of chip amplitude.
#### 3.2 What problems are presented after code wipe-off
After code wipe-off the continuous signal is still modulated by navigation data, this will introduce the problem of bits transition -> +1 becomes to -1.
For normal PLL, the bits transition can lead to unlock.
The solution is find an approach that is insensitive to the DATA BITS TRANSITIONS
#### 3.3 SOLUTION: COSTAS LOOP
The Costas loop is a special type of PLL used to track the carrier phase in the presence of data modulation.  
From the Costas loop structure, we can observe two branches: the in-phase branch, generated using a cosine replica, and the quadrature branch, generated using a sine replica.
After mixing and low-pass filtering, the two outputs are the I and Q components. The phase error can then be estimated as: $\theta = atan(\frac{Q}{I})$ .
The implementation of PLL model is used for Carrier tracking and Navigation data bit decoding.

##### 3.3.1 Why FLL and PLL
FLL is also employed in GNSS COMMUNITY, it tracking the frequency ignoring the phase to provide a frequency estimation to initialize the carrier wipe-off.

Once FLL get correct frequency, the PLL works on a narrow band.

This combination can achieve convergence in a short time, then just using PLL
