# How acquisition works

## 1.Based on Correlation 
### 1.1 how correlation works
compare the local replica with received one, the peak is the match point.
Due to the periodic nature of GNSS signal, it turns out to be circular correlation
#### 1.1.1 Difference of Linear correlation and circular correlation
Linear correlation: truncate the signal that outside
circular correlation:  Wrap around cyclically
### 1.2 Why DFT and IDFT
To compute more efficient of circular cross-correlation( $O(N^2)$ -> $O(Nlog(N))$
1. Do DFT(use FFT) of received signal and local carrier
2. simple product ($X[k]$*$Y[k]$) where $X[k]$= $\sum_{n=0}^{L-1} x[n]e^{-j2\pi n\frac{k}{L}}$ , $Y[k]$ = $\sum_{n=0}^{L-1} y[l] e^{-j2\pi \frac{l}{L}}$
3. $IDFT(X[k]Y^*[k])$ = $R_{x,y}[n]$
## 2. What is acquisition stage doing
Only one thing, searching for a rough value of delay $\tau$ and doppler shift $f_d$ , $P(\tau , f_d)$
Math model:
$Y_{IF, i}[n]$ = $\sqrt(2P_R)*C_i^b(nT_s - \tau)*d_i(nT_s - \tau)*S_c^{(b)}(nT_s - \tau)*sin(2\pi (f_IF-f_d)nT_s + \phi)+w[n]$ 
### 2.1 How to do this
#### 2.1.1 Base on Maximum-Likelihood (ML)
There are received signal $y[n]$ and local test signal $\bar{r}[n]$
ML estimation of P:
$\hat{p} = argmax_{\bar{p}}\sum_{n=0}^{L-1}y[n] \bar{r}[n]$

Normal correlation function limitation, only can calculate delay $\tau$ 
### 2.2 Cross ambiguity Function (CAF)
Can calculate the $\bar{\tau}$ and $\bar{f}_d$ at the same time 
$R_{y,r}[\bar{\tau},\bar{f}_d]$ = $\frac{1}{L}\sum_{n=0}^{L-1}Y_{IF}[F] C_i(nT_s - \bar{\tau}) S_c(nT_s-\bar{\tau}) e^{(j2\pi (f_IF-\bar{f}_d)nTS)}$
#### 2.2.1 How it works
1. take the modulus square of CAF $S^2_{y,r}{(\bar{\tau},\bar{f}_d)}$  = $|R_{y,r}{[\bar{\tau},\bar{f}_d]} |^2$
$\hat{P}_{ML} = argmax_{\bar{P}_{(\bar{\tau},\bar{f}_d})}S^2_{y,r}{(\bar{\tau},\bar{f}_d)}$ 
To find the Maximum modulus square value, search space come in.
$\Delta{\tau}$ and $\Delta{f}$ represent the grid dimension, find a grid that make the modulus value is biggest
## 3. Search Space (SS)
### 3.1 Time dimension
1.Number of bins $N_{\tau} = \frac{T_{coh}}{T_s} = f_s * T_{coh}$
where $T_{coh}=L*T_s$ , L represent the number of samples in 1 code period.
$\hat{\tau}$ is not propagation delay, but just a delay of 1 code period, called phase misalignment, code phase.
2.Frequency bin size: rule of thumb, empirical rule, $\Delta{f}=\frac{2}{3*T_{coh}}$ 
$N_f = \frac{Range}{\Delta{f}}$
3.Frequency searching range.
   For normal relative motion: (-5kHz, 5kHz) 
   For high relative motion: (-10kHz, 10kHz)
### 3.2 Two Schemes
1. Serial Scheme: see the scheme pics in slides
2. Parallel Scheme: Using FFT/IFFT accelerate the searching speed, reduces the complexity of serial acquisition systems. 
## 4. Receiver performance parameter
TTFF, Time To First Fix. 
1.cold start: no extra information, find the best match in the SS one grid by one grid. 
2.hot/warm start: There are some extra information can be used. For instant, clock, last know position, etc. Just find the best match in a specific area of SS, reduce the computation time.
