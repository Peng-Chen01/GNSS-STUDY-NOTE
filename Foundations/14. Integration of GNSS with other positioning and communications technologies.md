## 1. Assisted-GNSS (A-GNSS)
It may act at physical layer for acquisition and tracking aiding by providing coarse doppler shift and code phase  to reduce the Time To First Fix(TTFF), power consumption, increase the sensitivity.
It may act at pseudo-range level to provide correction service, and also at PVT computation level.

### 1.1 Positioning server
Two modes:
1.  Handset-based mode (MS-based Mode): Networks provide assist data, unit compute the location by itself.
2. Handset-assisted mode (MS-Assisted Mode): Unit send data to network, and computation done by network, then send back to unit.

How is the communication channel between unit and server: 
1. Control plane, pre-defined cellular network signal structure, like GSM and WCDMA
2. User plane, TCP/IP data connection
### 1.2 Type of assistance
1. Acquisition: reduce the search space and also TTFF by providing Mobile station(MS) with Coarse information 
2. Sensitivity: Providing list of visible satellites, Coarse acquisition information and expected navigation message to enable fast data wipe-off and longer integration time
3. Network assistance: improve accuracy, compute via network resources
## 2. Non-Geometric Techniques
1. Fingerprinting
2. Proximity Positioning: WIFI, Bluetooth, RFID
3. Near-Field Ranging(NFR)
## 3. Positioning in mobile network
Two Approach, depend on who does the calculation: 
1. Terminal-based positioning(Mobile station based), Only implemented use GNSS
2. Network-based positioning(Base-station-based), Cellular network approaches

Network based positioning, cell identification(CI), Angle of arrival(AOA), Time of Arrival(TOA), TDOA(Widespread technology). However, these techniques are rarely used due to the cost of the adaptation of the network to positioning purpose.

Indoor position: WIFI, proximity sensing, Trilateration, Fingerprinting
